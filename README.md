# Lumen Advisory: Demo Website

A sample website I designed for a fictional company-setup consultancy, to show my web design approach.

![Homepage screenshot](screenshot.png)

## About this project
- **Purpose:** Portfolio demo (fictional business)
- **Built with:** HTML & CSS
- **Sections:** Home, Services, How it works, Common questions, Contact

## Design goals
- Calm, editorial look with plenty of white space
- Clear structure that explains the service step by step
- Easy to read on phones and desktops
